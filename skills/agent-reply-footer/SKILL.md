# 回复收尾规则配置

把通用约定写入用户指定范围的 AGENTS.md，并按要求应用于当前对话。技能负责配置，日常回复遵循已加载规则，无需反复调用技能。

## 范围与操作

- 用户只要求在当前对话采用时，读取 [规则模板](assets/reply-footer-rules.md) 后直接采用，不写文件。
- 用户要求持久化时，遵循其指定的全局、项目或两者范围。未指定范围则只在当前对话采用，说明持久化还需指定范围；不要自行修改全局设置。
- 全局 AGENTS.md 位于有效 Codex home（默认 ~/.codex，可能由 CODEX_HOME 指定）；项目文件按用户指定项目和已有指令确定。不要写死作者的用户名、系统或项目路径。
- 读取目标文件及已知生效的 AGENTS.override.md 或下级覆盖规则。只处理与收尾及本套更新约定直接相关的部分，不覆盖整份已有文件，不修改无关的规则更新机制。

## 安装与更新

1. 读取 [规则模板](assets/reply-footer-rules.md) 和目标文件。文件不存在时可在已授权范围创建。
2. 用模板替换已有同用途段落；没有对应段落则追加。识别旧的“回复收尾规则／回复收尾”和本套“规则更新约定”，避免重复。保留其他内容；混合章节只替换相关条目，无法确定边界时说明具体冲突并澄清。
3. 内容一致时不重复写入。保留用户明确要求的定制；若更新会覆盖定制，先说明差异并按用户选择处理。
4. 回读确认目标段落、去重情况及其他内容保留情况。只报告实际写入的路径。
5. 用户要求当前对话生效时，从本轮起采用模板中约定；不清空任务进度，不声称其他已有对话也已更新。若另有已知生效文件覆盖新版，报告具体位置；仅在用户授权范围内同步修改。

规则更新后，其他已有对话可发送：

> 请重新读取 <规则文件实际路径> 中的“回复收尾规则”和“规则更新约定”，从本轮起采用新版，替换同一事项的旧要求，保留当前任务进度和其他有效约束。

文件系统不可用时，提供可复制模板，不声称已持久化。仅安装本技能并不等于已将规则写入 AGENTS.md；不承诺自动热更新所有聊天。

## 移除

用户要求移除时，仅删除本套已识别规则段落，保留其他内容并回读。用户要求恢复旧规则时，只使用实际保留的旧内容或用户提供的版本，不编造旧版本。删除技能目录本身不会自动清除先前写入的 AGENTS.md 规则。
