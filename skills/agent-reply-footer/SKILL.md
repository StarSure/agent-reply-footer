# 配置回复收尾

用 [规则模板](assets/reply-footer-rules.md) 配置用户选择的范围，保留其他规则和当前任务进度。

## 启用或更新

1. 确定用户要用于当前对话、当前项目、全局还是全局及项目。未指定时先在当前对话采用，不自行修改全局文件。
2. 读取模板和目标文件。全局文件使用有效 Codex home 下的 `AGENTS.md`（默认 `~/.codex`，可能由 `CODEX_HOME` 指定）；项目按当前工作区及已有指令确定。检查已知覆盖文件是否会影响生效，不写死本机路径。
3. 在已授权范围创建缺失文件，或替换已有同用途的收尾段落和本套更新约定。没有则追加，相同则不重复写；保留其他内容及用户明确要求的定制。混合章节只改相关条目，只有无法确定替换边界或定制冲突时才澄清。
4. 回读确认写入正确、没有重复、其他内容保留。只报告实际修改的文件；没有文件权限则提供模板，不声称已写入。
5. 用户要求当前对话立即启用时，从本轮起采用新版。若已知覆盖规则仍有冲突，在授权范围内处理并说明实际状态。

只在当前对话采用时，读取模板后直接应用，不写文件。技能负责配置，后续收尾由已加载的规则承担，无需重复调用。

安装本技能并不等于已经启用。其他已有对话需分别通知重读更新后的规则，不能声称全部自动生效。

## 移除

仅删除用户指定范围内本套收尾规则和更新约定，保留其他内容并回读。要求当前对话停用时也立即停止；删除技能文件夹本身不撤销文件中的规则。恢复旧版仅使用实际保留的内容或用户提供的版本。
