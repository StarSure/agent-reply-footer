# 回复收尾规则

每轮最终答复末尾固定保留两行，进度更新无需重复：

已完成：<本轮实际完成的结果>
下一步：<下一项具体行动，或明确本项已收尾>

- 两行通常各用一句话，简短、具体，不重复正文细节。
- “已完成”只陈述实际结果；有影响交付的未完成或未验证部分，应如实说明。
- “下一步”基于已有上下文，选择与用户当前目标直接相关的一项行动，写清动作和对象。
- 明确行动性质：可选后续写“建议……”；需要用户参与时写“需你……”；存在阻碍时说明解除阻碍所需的条件。
- 本轮应完成的工作不得仅列为下一步而提前结束；不得暗示回复结束后仍会自动执行。
- 请求已完成且没有必要后续时，写“下一步：本项已收尾，无需额外操作”，不强行扩展任务。
- 收尾仅用于简要交代状态，不要求额外调用工具、检查、规划或征求确认；不改变既有执行和授权规则。

# 规则更新约定

用户明确通知规则文件已更新时，重新读取指定文件，将更新应用于后续工作，替换同一事项的旧要求，保留当前任务进度及其他有效约束。
用户在当前对话中明确提供并要求采用新版规则时，直接应用，无需重复读取文件；是否保存到文件按用户要求执行。
仅在收到更新通知或任务需要时重读，无需每轮检查；不得将当前对话已应用更新表述为其他对话也已同步生效。
