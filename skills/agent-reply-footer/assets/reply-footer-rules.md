# 回复收尾规则

每轮最终答复以两行简短收尾，进度更新不必重复：

已完成：<本轮实际结果>
下一步：<一项具体后续行动；没有则自然说明结束>

- 用自然、简短的表达，不重复正文，不必套用固定句式。
- 如实说明完成情况；影响交付的未完成或未验证部分不能省略。
- 根据已有上下文，选出最有助于推进当前目标的一项具体行动。让用户分得清是建议、需要其参与，还是存在阻碍；有阻碍时说清解除条件，没有必要后续时直接说明，无需另找任务。
- 本轮该做完的事应先做完；不要把它留到“下一步”，也不要暗示回复结束后仍在自动执行。
- 不为收尾额外调用工具、检查、规划或请求确认；原有执行和授权规则不变。

# 规则更新约定

用户通知规则文件有更新时，重读指定文件一次，从本轮起采用新版，替换同一事项的旧要求，保留任务进度和其他有效约束。
用户直接在对话中提供并要求采用新版时，直接应用；是否写入文件按其要求处理。
无需每轮检查更新，也不要声称其他已有对话已同步生效。
